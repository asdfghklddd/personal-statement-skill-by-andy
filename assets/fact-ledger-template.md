# Personal Statement 事实账本

这是内部工作表，不是交给学校的附件。先填已有信息，再用最少的问题补关键缺口。

## A. 任务

- 目标学校、项目全称、入学年份：
- 官方题目原文：
- 字数/字符数/页数及计数口径：
- 文书名称：PS / SOP / motivation letter / PHS / research statement / combined：
- 学位层级与项目性质：本科 / 授课型硕士 / 研究型硕士 / 博士 / 其他：
- 申请系统或地区：
- 其他文书及分工：
- AI 辅助、协作写作或独立完成要求：

## B. 核心问题

- 申请人现在想处理的具体问题（一句，不写“热爱”）：
- 已经做过什么：
- 哪一步仍做不到，为什么需要这个项目：
- 近期可验证的下一步：

## C. 经历证据

### 经历 1

- 时间、场景、背景：
- 团队分工与本人边界：
- 本人做了什么，为什么这样做：
- 结果、产物、反馈或数字：
- 结果的范围、局限和待核实项：
- 这件事改变了什么判断：
- 与申请问题/项目的关系：

### 经历 2

- 时间、场景、背景：
- 团队分工与本人边界：
- 本人做了什么，为什么这样做：
- 结果、产物、反馈或数字：
- 结果的范围、局限和待核实项：
- 这件事改变了什么判断：
- 与申请问题/项目的关系：

### 经历 3（仅在题目需要另一类证据时）

- 时间、场景、背景：
- 团队分工与本人边界：
- 本人做了什么，为什么这样做：
- 结果、产物、反馈或数字：
- 结果的范围、局限和待核实项：
- 这件事改变了什么判断：
- 与申请问题/项目的关系：

## D. 外部来源与项目匹配

- 论文、书籍、媒体、讲座或政策数字：作者/机构、标题、日期、链接、观点归属、定义和范围：
- 申请人如何比较、检验或修正该来源：
- 项目资源（课程、方法、实验室、研究组、实践）及官方原文：
- 计划如何使用资源：
- 为什么不是相邻学位或其他路径：
- 资源与当前缺口的对应关系：

## E. 边界与声音

- 需要解释的成绩下降、空档或转向：
- 不应写入的健康、家庭、身份或隐私信息：
- 申请人自己的 80–120 词英文样本（如有）：
- 明确不采用的推断或未经授权成果：

## 开稿前最低检查

- [ ] 题目、文书类型和限制已确认
- [ ] 至少两条经历有本人动作、结果和认识变化
- [ ] 外部观点与本人判断分开
- [ ] 至少一条项目资源来自当前官方材料或用户提供的页面
- [ ] 数字有时间、口径、来源或已标为待确认
- [ ] 缺口用 `[待确认：...]` 标记，不用想象补齐
