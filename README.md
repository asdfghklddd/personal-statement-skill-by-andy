# Personal Statement Skill by Andy

一个面向 Codex 的留学申请文书 Skill，用于 Personal Statement、Statement of Purpose、动机信和研究型文书的素材挖掘、写作、改写、项目匹配与质量检查。

它以申请人可核实的经历、个人贡献、认识变化和当前项目要求为基础，支持本科、授课型硕士、研究型硕士/博士及跨项目适配。Skill 会区分 PS、SOP、Research Statement 和单独研究计划，不把范文、评论或外部案例当作申请人事实。

## 使用

保留仓库内的目录结构，将仓库内容安装为 `write-study-abroad-ps` Skill；在 Codex 中可显式调用 `$write-study-abroad-ps`。

主要入口是 `SKILL.md`。详细的事实账本、写作工作台、项目分流、语言编辑和质量检查位于 `assets/` 与 `references/`。

## 边界

Skill 不承诺录取结果或 AI 检测结果，不编造经历、数字、导师关系或项目资源。具体申请题目、字数、AI 使用规则和上传要求以当期官方页面及申请系统为准。
