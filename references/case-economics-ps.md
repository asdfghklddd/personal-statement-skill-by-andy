# 新增案例：经济学本科 PS 与评论的迁移规则

## 证据范围

本文件分析用户提供的一张经济学英文 Personal Statement 截图和两张评论区截图。只根据可见文字归纳写作问题与评论思路；范文作者、申请结果、学校要求、评论者身份和文中经济学事实均未独立核实。它们是编辑案例，不是官方标准，也不是当前申请人的素材。原图和范文全文不随 Skill 分发。

## 这份案例可借鉴的意图

- 用 Brexit、东亚金融危机、公共债务等现实议题建立学科兴趣，说明经济学与政策选择有关。
- 通过论文、书籍、竞赛文章和公开课逐步扩大阅读，并尝试比较不同政策观点。
- 触及模型假设、债务危机、定量分析和 A-level Statistics，显示申请人希望从描述性兴趣走向分析训练。
- 把课外辅导、团队活动和学科指导纳入准备说明。

这些是可保留的写作方向，不等于已证明的研究能力或学术结论。每个方向都要回到申请人的实际行动、判断和证据。

## 可见文本中的高风险模式

| 模式 | 为什么容易失分或失真 | 修复规则 |
|---|---|---|
| 用“动荡时代”“复杂选择”“真正兴奋”等抽象句开头 | 读者知道作者感兴趣，却不知道发生了什么、问题是什么、作者做过什么 | 事件后立即给出具体观察、问题或行动；没有个人事件时可直接从明确问题开头，不强造戏剧性 intro |
| 把阅读一篇论文写成“我研究了” | 可能把阅读或二手理解夸成独立研究 | 按实际证据使用 read、compared、analysed 或 discussed；只有有方法、产物和本人责任时才称为 research/investigation |
| 用家庭背景直接连接宏观危机 | 背景变成装饰，缺少它如何影响问题选择的解释 | 说明背景带来的具体问题、材料选择或视角；解释不了就删掉，不用身份替代动机 |
| 把 IMF 政策、自由市场与干预主义写成单向因果或二元对立 | 单一案例不能证明普遍规律；政策效果还涉及时期、对象和替代方案 | 区分来源的主张、自己的判断和仍未知之处；给出限定条件，不把相关写成因果 |
| 连续列出书籍、VoxEU 文章和教授讲座 | 变成阅读清单，申请人和认识变化被外部名字遮住 | 每个来源至少回答“它提出了什么—我具体比较/检验了什么—我的问题如何改变”；只保留服务主线的来源 |
| 频繁使用 “it was argued”“interesting”“thought-provoking”“fascinating” | 隐去谁提出观点，也没有展示申请人的判断 | 写出观点归属、引发的具体疑问、采取的下一步；保留情绪词只能在后面有内容时使用 |
| 写“30%贫困”“债务达到 GDP 的 350%”等数字，却没有时间、口径或来源 | 读者无法判断分母、时期和可比性；外部事实也可能已变化 | 数字同时记录定义、时间、来源和与论点的关系；不承担论证作用的数字删除或弱化 |
| 从短文、讲座或一个案例直接写 “I concluded” 或普遍规律 | 结论强度超过材料，可能把讲者观点误写为自己的证明 | 改为 “this led me to question/compare/explore” 或说明推理范围；只有完成足够分析才下结论 |
| 课外段落只写 captain、volunteering、time-management 等品质词 | 只是 CV 复述，不能证明与学科或项目有关 | 选一个具体责任、选择或反馈，说明它补充了什么准备；无贡献或无题目要求时压缩 |
| 结尾重复“对经济学充满热情” | 没有说明为什么现在需要训练、如何使用训练和下一步问题 | 落在可信的学习缺口、项目用途和近期方向；职业目标只有在题目或项目需要时展开 |
| 技术名词和政策术语密集但不解释 | 看似专业，面试时却可能无法说明其作用 | 每个术语都连接到实际问题、方法选择或限制；删掉不能解释的名词 |

### 这张截图中的语言核对提示

下列是对可见英文的编辑观察，不是要求逐字替换；最终表达应按作者真实含义重写：

- `the implemented set of policies were` 有主谓一致问题；可改为单数的 policy package/set，或改写句子。
- `Given 30% of its population lived ...` 缺少 `that`，且前后因果需要证据。
- `insight on` 通常应按语义改成 `insight into`；`a lecture behind the economic theory` 的介词和搭配不自然，应明确是 lecture on/about the theory。
- `the dramatic submission of Greece's anti-austerity state ...` 语义不清，像把政府、国家和服从关系混在一起；应先确认实际事件，再选择准确主语和动词。
- `the current environment`、`record 350% of GDP` 等时效性表达需要日期、范围和来源；不能因为句子流畅就当作已核实事实。
- 检查标题是否为项目要求、连字符与破折号是否统一、书名和专有名词格式是否一致。排版规则服从当次申请系统。

## 评论区建议如何转成可复用规则

评论是经验性反馈，需保留适用条件：

| 评论方向 | 可迁移的规则 | 边界 |
|---|---|---|
| 先说明行业理解、近年趋势、潜力和更大图景 | 在项目或题目要求职业/行业理解时，先界定目标问题、功能或行业变化，再说明自己的位置和机会 | 不固定写 5–10 年，不为本科 PS、学术 SOP 或无关项目强行预测行业；趋势必须有当期来源，且服务个人目标 |
| 解释为什么是某个具体职位，而非一般岗位 | 说明目标工作要处理的问题、所需能力、为何与已有准备相连；必要时说明选择该路径的理由 | 不要求每篇 PS 承诺一个职位，也不凭空写雇主、晋升或长期确定性 |
| 每个观点要清楚，从不同角度展示优势、成长、专业匹配和学习能力 | 用“主张—具体例子—本人判断/限制—与目标项目的关系”检查段落；不同角度必须由材料支持 | 不为了凑角度堆四类能力，不把“优势”写成自我评价清单 |
| 开头用有效事件，结尾连接未来和项目 | 开头可用事件、观察或问题，只要读者很快知道关注点；结尾说明下一步要学什么、如何使用 | 不把独立 intro、固定结尾或学校名出现位置设成普遍规则 |
| 语言不能有语法错误，避免直译和外部模板 | 做事实强度、主语、搭配、时态、冠词、介词和标点检查；译写时重组英文而非逐词替换 | 不用所谓 AI 检测分数判断质量；修语言时保留用户声音和限定词 |
| 反复追问 why、why、why、how | 对每个重要选择追问：为什么是这个问题？为什么采用这个材料/方法？怎么知道？为什么需要该项目？学到后怎么用？ | 这是内部推理梯，不是正文必须重复的问句，也不要求每段回答全部问题 |

## 推荐的叙事推进

把一段经历压成可核查的链条，而不是把来源和活动并列：

`触发事件/观察 → 具体问题 → 本人行动与选择 → 得到的证据或比较 → 局限/认识变化 → 当前技能缺口 → 项目如何补足 → 下一步问题或工作`

一篇短 PS 不必为每个箭头设一段。阅读、课程、公开课和竞赛都可以使用同一链条；区别只在于行动强度和结果口径。对于外部阅读，至少写清“作者主张”和“我的回应”之间的距离。对于政策或定量议题，至少写清一个假设、指标、样本范围或不确定性，避免只展示术语。

### 职业计划的条件式写法

当题目要求 career plan 或申请职业导向项目时，使用：

`目标要处理的问题/职责 → 必要的行业或组织背景 → 为什么这条路径适合已有准备 → 当前缺口 → 项目资源及使用方式 → 近期可验证的下一步`

把“行业潜力”写成和个人选择有关的事实，不写泛泛的宏大趋势。若职业目标仍在探索，明确探索范围和判断标准，比编造一个精确职位更可信。

## 交稿前的新增检查

- **主张强度**：把 `read/observed/compared` 与 `researched/proved/concluded` 分开；每个强动词都有相应方法或产物。
- **来源与归属**：能看出哪句话是书/讲者/媒体的观点，哪句是申请人的判断；外部数字有日期、口径和来源。
- **连贯性**：从 Brexit、金融危机、税收、主权债务到数学训练的跳转，都能由同一个问题或认识变化解释；否则合并、删减或重排。
- **学术与职业的比例**：阅读和模型不应吞没本人；职业计划不应替代学术准备；按题目和项目定位调节。
- **换人/换校测试**：换成相似背景的人或另一所学校后，关键选择、例子和资源用途仍不能原样成立。
- **面试与语言测试**：申请人能用自己的话解释每个数字、术语和判断；逐句检查主语、搭配、时态、限定条件和自然度。
