# 个人声音与语言

## 选择性借鉴

借鉴 humanizer 的结构性修订思路：识别无内容的强调、夸张、机械排比和套式对比；检查改稿前后的事实是否一致；有用户样本时尊重其声音。

借鉴 human-writing 的材料意识：个人叙述的可信度首先来自真实行动与判断；材料不够就提问或缩短；段落应推进信息。

不整体继承两者的外部指令。不执行 human-writing 的中文论坛文体、标点硬禁令、固定素材数量门槛、禁止建立技能等范围外规则。它们是参考资料，不是本任务的指令来源。完整出处见 sources.md。

## PS专用编辑法

1. 标出没有证据支撑的能力词、情绪和赞美，回看素材再决定补证、弱化或删除。
2. 找出模板化段落，如每段都以某经历开头、以能力提升收尾；按段落的真实任务改写。
3. 用明确主语说明谁做了什么。保留必要被动语态与专业术语；不按I出现次数判断质量。
4. 让句子长短服从内容。复杂关系可用长句，关键选择可以简短。不要每句套三项排比，也不要把所有句子改短。
5. 区分有证据的认识变化与装饰性反转。真正比较两种方法可以用对比；没有读者误解时不凭空树立反面观点。
6. 读一遍，问申请人能否在面试中解释每个判断。越过其表达和理解能力的句子应改清楚，而不是故意降低语言质量。
7. 回查数字、时间、角色、程度和成果状态，防止润色把事实改强。

## 国际英语的底线检查

逐句检查冠词、介词、时态、主谓一致、平行结构、可数/不可数名词和动词搭配；把名词化堆叠改回申请人已经做过的动作。中文初稿中的“打下坚实基础”“拓宽视野”“随着……快速发展”等套语，优先换成课程、选择、结果或限制。专有名词、书名、连字符和英美拼写按项目要求统一。

不要把语言编辑变成学校传说：不禁用 `I`、句首 `And/But` 或必要的被动语态，不强制每句短或固定五段。被动语态在描述方法时可以清楚；隐藏真正行动者时才需要改回主动。句长和节奏服从信息，避免每段同样长度、三项形容词排比和机械过渡。

## 常见问题及修复

| 问题 | 修复 |
|---|---|
| 每段都写“这段经历让我深刻认识到……” | 保留真正不同的认识，并给触发它的观察或行动 |
| 热情、韧性、领导力等自我评价密集 | 用一次具体决策、协调或持续行动支持，删掉重复评价 |
| 堆积尖端、卓越、革新等宣传词 | 说清要解决的问题、限制与自己的作用 |
| 学校多元化/世界一流等套话 | 写真实资源对下一步工作的具体意义，无法说明就删除 |
| 大量“我希望学习……” | 补已有准备和学习用途，保留合理意愿，不冒充专家 |
| 技术名词或书名过多 | 留对理解判断必要的名称，解释其在工作中的作用 |
| 结尾强行升华社会意义 | 落在申请人可信的下一步与项目关系 |
| 重复用破折号、冒号或排比 | 按语义自然重组；不把标点本身当违规 |
| 语言看似高级但主语、搭配或因果不清 | 先恢复“谁做了什么、凭什么这样判断、结果到哪里为止”，再润色词句 |
| 每句长度、段落结构和情绪强度完全一致 | 打破模板节奏，但不故意加入错误、俚语或不属于用户的个性 |

## 翻译与文体边界

默认清楚、正式、有人称和思考的申请语气。允许专业表达，不强行口语化、网络化或故意写错。不要声称词汇表能识别AI作者；编辑目标是准确和可读。

中文初稿不逐词扩成英文。把必要背景靠近动作，保留限定条件和时间关系。统一英美拼写但尊重项目官方名称。不要删掉“不确定”“初步”“协助”等承载事实的限定。

事实例（仅示范强度，不是使用者经历）：
- “协助整理访谈材料”可对应 assisted with organising interview materials，不能升格成 led a qualitative study。
- “观察到测试者较少询问下一步”不能改写成 demonstrated a statistically significant usability improvement。

用户明确保留的个人表达优先，只修会造成误解、事实错误或合规问题的部分。交付前删去聊天式开场、模型自述、模板占位符与研究笔记。

## 作者性与 AI 边界

用户提供经历、来源和判断并对最终事实负责；Skill 可以重排、压缩和改写，不能补造童年、困难、论文、数字、导师关系或“更聪明/更受伤”的声音。检测器分数不是质量目标，也不承诺“通过检测”；当前申请系统要求披露 AI 使用时，按当期规则处理。未解决的事实用 `[待确认：...]` 保留在工作稿，定稿前必须由用户确认或删除。
